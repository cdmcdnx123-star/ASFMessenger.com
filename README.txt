ASF Messenger (demo)
Open index.html in Chrome. Demo OTP code: 123456. Data is stored in your browser only.

REAL GOOGLE LOGIN: login screen par "Set Google Client ID" dabayen aur apna Web client ID paste karein. App ko http://localhost (python -m http.server 5500) ya https se kholein, double-click se nahi.
ASF AI: tap the round "AI" button at the top, then Settings -> "ASF AI key" to add your Anthropic API key.
PROFILE: Settings -> pencil icon (cover photo, profile photo, status, description, address).
